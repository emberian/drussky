# Packaged Sound Focus originals

The full castle/lock WAVs here are byte-for-byte copies of the existing local
synthetic originals identified in `silero-stress-v1/measurements.json`. Their JSON
files preserve the original synthesis metadata. They are **complete carrier
sentences**, not the previously published analyst-selected word crops.

`manifest.json` also references the already committed isolated `Лук.` / `Люк.`
originals RQ02/RQ03. It records exact utterance/member versions, source text, encoded
byte hashes and byte lengths. No audio was generated, cropped, normalized,
resampled, or acoustically inferred during packaging.

The shared `published_at_ms` is an assigned package publication epoch so importing
clients can emit deterministic metadata. It is not a recording/synthesis timestamp.
The original source metadata and quality limitations remain intact. Intended
meaning labels and successful byte/contract checks do not certify pronunciation.
