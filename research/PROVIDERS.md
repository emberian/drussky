# Primary AI teaching providers

Checked 2026-11-05. The AI teacher carries explanations, examples, textual corrections, practice preparation and review. Human conversation is welcome; a formal human tutor or reference-approval ceremony is not a prerequisite. AI feedback retains its own provenance. Speech models and acoustic assessment are separate interfaces: see [speech providers](SPEECH_PROVIDERS.md).

## Implemented paths

`rufren-tutor` exposes shared request/result DTOs without server dependencies. The private relay owns the server feature, authentication, model access and process limits. Two explicit text backends exist:

| Backend | Configuration | Default quality policy | Accounting |
|---|---|---|---|
| Existing Claude Code login | `RUFREN_TUTOR_PROVIDER=claude_cli`, `RUFREN_CLAUDE_BINARY=/absolute/path/to/claude` | CLI `opus` alias, `high` effort for interactive teaching; actual resolved model recorded | Existing plan/quota; no API-dollar reservation claimed |
| Anthropic HTTP API | `RUFREN_TUTOR_PROVIDER=anthropic`, server-only `ANTHROPIC_API_KEY` | Fixed `claude-opus-5-5`, `max` effort, adaptive reasoning | Model-specific conservative API token/cost reservation |

Omitted/disabled selection leaves the service unavailable. No browser/mobile binary contains model credentials. The app authenticates to its private relay with its session key, displays what is submitted and makes explicit teacher requests; mounting the app does not upload a notebook. No automatic paid fallback, recharge, account linking or billing mutation exists.

The CLI `opus` alias follows the latest Opus available through the installed CLI/provider. Official current documentation resolves first-party Opus to 5.5; different providers or account policies can differ, so returned model identity is retained and unexpected family changes rejected. Other CLI families/efforts require explicit `RUFREN_CLAUDE_MODEL=sonnet|haiku|opus` and `RUFREN_CLAUDE_EFFORT=low|medium|high|xhigh|max`. Interactive effort defaults to `high`; `max` remains an explicit option for offline preparation. Status identifies the configured alias/effort without pretending that an alias is a resolved model ID. `RUFREN_CLAUDE_TIMEOUT_SECONDS` defaults to 100 and accepts 1–100. Organization policy can cap effective effort. Opus selection is a quality-first engineering choice, not evidence that its Russian teaching is infallible. [Official model configuration](https://code.claude.com/docs/en/model-config).

## Exact teaching and assessment contracts

Authenticated routes are `GET /api/teacher/status` and `POST /api/teacher/teach`. The legacy `/api/tutor/status` and `/api/tutor/suggest` routes remain compatible with general text assistance. `TeacherRequest` uses `mode` and `input`:

- `teach_lesson`: request/lesson identity, title, objective, material and optional learner context. The response must include an explanation, examples, practice and a useful next step; it has no answer grade. New practice supplies a concrete Russian passage, its English meaning and a reading/writing skill so it can become an executable task. Older cached practice without these additive fields remains readable.
- `answer_feedback`: request/revision identity, optional saved-attempt/context/exercise identities, skill, exact task/prompt/reference/response, recorded cues and `written_text` or `transcript` evidence, with an optional exact confirmed-transcript event identity. Its structured AI verdict is `correct`, `partly_correct`, `incorrect` or `uncertain`, with an optional natural complete answer and precise corrections.

The gateway echoes the validated request itself rather than accepting model-generated bindings. Nonempty correction originals must occur literally in the submitted response; an empty original/replacement permits insertion/deletion, while both cannot be empty. Clients compare the echoed binding to the intended question before applying feedback. Root app persistence maps saved-answer feedback into a distinct core `AiAssessmentRecorded`, preserving the exact immutable response/context. Unsaved feedback stays a draft/result until a corresponding saved attempt exists. It never becomes a human judgment.

`TeacherResponse` contains the echoed request, structured content, provider/model/response/prompt-version provenance and usage accounting. The current teacher prompt version is `rufren-ai-teacher-v2`; the CLI adds `+cli-structured-v1` for its direct schema-helper instruction. Teaching carries `ai_generated_teaching` provenance, usable as AI teaching without a human approval gate. General legacy suggestions retain `unreviewed_ai_suggestion`. Neither label is evidence of external review or measured mastery. The model may assess language content in writing or a transcript; it cannot hear pronunciation, stress quality, fluency or intelligibility from text. It may explain pronunciation patterns without pretending to have assessed the learner's audio.

## Subscription-backed local Claude gateway

This is the installed, unmodified Claude Code programmatic interface, not extraction or reuse of an OAuth token in a custom HTTP client. Rufren launches only the explicitly configured executable, checks its native authentication status, sends bounded task JSON on stdin and parses structured output. Credentials remain under the CLI's own handling. API-key/provider-override authentication is rejected by this adapter; choose the explicit HTTP API backend for API credentials. [Programmatic CLI documentation](https://code.claude.com/docs/en/headless).

The adapter uses an operation-private working directory, `--safe-mode`, a replacement system prompt, no ordinary tools, an empty strict MCP configuration, disabled hooks/commands/browser integration, no session persistence and at most two schema turns. It sanitizes inherited environment, retaining only necessary runtime/auth-configuration paths. A single 100-second maximum deadline covers authentication and generation; stdout is limited to 128 KiB and stderr is drained concurrently with a 16 KiB cap, never exposed as provider text. Unexpected tools, MCP servers, API-key source, model family, multiple models, malformed output or missing response identity fail. Only the CLI's internal `StructuredOutput` schema helper is permitted. Owned child handles/PID files support bounded termination; cancellation may leave an operation directory rather than deleting it under a running child.

Safe mode preserves native authentication while disabling customizations. `--bare` skips subscription authentication, and `--restricted` skips user configuration; they are not interchangeable. In this account investigation, adding restricted mode selected a different stale login. Full Opus/max lesson requests timed out, including after adding a CLI-only instruction to call `StructuredOutput` directly. The current interactive default retains Opus with `high` effort; explicit `max` remains available for preparation. A real full lesson on resolved `claude-opus-5-5` completed in 18.9 seconds through the actual UI; keeping an example, generating Milena speech, playback and completed listening took 21.2 seconds total with no browser errors. This acceptance predates the subsequent executable-practice/confirmed-transcript schema additions, which require their own composed checks. Metadata-only diagnostics record phase timing, model resolution, assistant/helper counts, stream byte counts and known stop/error categories without bodies, identities or credentials. The bounded deadline stays 100 seconds, with a 110-second teacher-only relay deadline below the existing 120-second app limit. Facts/assets retain 60 seconds; there is no automatic generation retry. The corrected isolated safe-mode probe preserved the intended configured login and successfully returned one public structured fixture on Sonnet 4.6 in about 3.4 seconds. Tools were limited to the internal schema helper and MCP was empty. No credentials were printed, copied or changed. That earlier probe established subscription-backed transport; the later Opus/high UI journey established the composed teaching path described above. Neither establishes acceptance of subsequent schema changes. No further live probe is implied. [CLI reference and safe-mode behavior](https://code.claude.com/docs/en/cli-reference).

The service is for a trusted personal host/installed CLI. Managed administrative policy still applies; this is not a sandbox for arbitrary executables or hostile machine policy. The shared service allows one operation at a time and a configurable request count. `UsageAccounting::SubscriptionQuota` explicitly distinguishes it from API prices. Zero direct API-dollar estimates do not mean unlimited/free subscription use; account limits remain authoritative.

## Anthropic API model and bounds

The HTTP adapter calls the official Messages and token-counting endpoints with server credentials and redirects disabled. It submits the same system/task/schema/reasoning configuration to preflight, rejects estimated input above 7,680 tokens (512 headroom below 8,192), then allows at most 8,192 total output tokens for reasoning plus the structured reply. Adaptive reasoning is required on Opus 5.5; disabling it would return an error. The configured effort is `max`, and reply instructions ask for compact teaching while leaving reasoning room. The parser accepts bounded thinking/redacted-thinking blocks but forwards only one schema-valid text result. [Messages API](https://platform.claude.com/docs/en/api/messages/create), [structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting), [effort/reasoning](https://platform.claude.com/docs/en/build-with-claude/effort).

Optional `RUFREN_TUTOR_MODEL` selections use distinct documented standard rates, not the default model's price:

| Model | Input / output per million tokens | Maximum reservation per attempt |
|---|---|---|
| `claude-opus-5-5` (default) | $4 / $20 | $0.196608 |
| `claude-sonnet-5-5` | $2 / $10 | $0.098304 |
| `claude-sonnet-4-6` | $3 / $15 | $0.147456 |

Unknown/unpriced model IDs fail configuration. No caching, fast mode, tool/search/file execution or automatic retry is requested. Default `RUFREN_TUTOR_SESSION_BUDGET_MICRO_USD=800000` ($0.80) accepts 1–5,000,000; `RUFREN_TUTOR_MAX_REQUESTS=20` accepts 1–1,000. The admitted attempt retains its full reservation after failure/cancellation, because generation may already have been billed. Clones share limits. Restart resets them; these are process-local application estimates, not persistent account limits or invoice guarantees. Prices/account/platform charges can change. [Official pricing](https://platform.claude.com/docs/en/about-claude/pricing).

The original general-text request accepts 8,192 UTF-8 bytes plus 2,048 optional context bytes. Teacher fields have individual bounds, including an 8,192-byte exact question/response/reference allowance, and an aggregate serialized request cap of 24 KiB. Serialized provider requests are capped at 32 KiB, responses at 128 KiB including chunked bodies, and structured fields/arrays have separate limits. The HTTP operation has a 100-second whole deadline and 5-second connect limit. Relay teacher bodies are capped at 32 KiB. These caps can reject a combined task whose individual fields fit; split a large task into useful learning steps rather than silently truncating its exact question or answer.

CLI prompts share those byte/structured bounds. Its reported token usage aggregates up to two schema turns and is bounded separately at twice the per-call token limit. The request counter, stream caps and deadline apply; API-dollar reservations do not pretend to limit subscription quota.

## Credentials, entitlements and evidence

A chat plan is not a universal API credential. Anthropic documents API-credit benefits for eligible plans after a Console organization is linked, but actual organization, balance, expiry and continuation after credit exhaustion must be checked privately. No organization linking or billing change was performed. Named API credentials were absent from the inspected process environment; only presence was inspected. The successful local CLI path uses its existing native login instead. [Claude API-credit terms/help](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-ultra-and-team-plans).

OpenAI/Gemini/Grok chat subscriptions do not establish configured application API access. No alternative text adapter is enabled merely because a subscription exists. Speech generation has its own explicit provider/limits; learner-audio assessment still needs a real audio-evidence contract and validation, not a transcript proxy.

The local speech path separately passed real public Milena generation. Logs are under ignored `.local/logs/`. The corrected CLI fixture and the later full Opus/high UI journey succeeded.
